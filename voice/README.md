# 统一配音 · voice/

「芯品发布会」配音标准库：基准音色 ＋ 录音规范 ＋ 质检工具。

用户每期自行录制分段配音（沿用已有流程），agent 按本标准质检、
输出每段精确时长，供分镜"先配音定出准确时长"排时间轴。

## 目录

- `reference/`：基准音色样本（sample1~6.mp3 ＋ 同名 .txt 文字稿）
- `check.py`：配音质检工具（纯本地，无需 API Key）

文字稿取自分镜脚本配音稿原文（已请用户校对）。

## 工作流程

1. 用户按分镜脚本配音稿录制分段音频：`seg1.mp3`、`seg2.mp3`……（有几段录几个）
2. agent 跑质检：
   ```bash
   cd voice
   python check.py --segs ./new_episode_segs --script peiyin.txt --out ./out
   ```
3. 得到 `out/manifest.json`（每段文字、字符数、精确时长），按此时长排分镜时间轴、做画面、压字幕。

## 录音规范

- 分段与配音稿段落一一对应，`seg1.mp3` 对第 1 段……
- 格式：mp3（192kbps 以上）或 wav；单声道即可
- 语速 4~5 字/秒；无 BGM、无杂音、无房间回声
- 每段首尾留约 0.3 秒静音，方便剪辑

## check.py 质检项

- 文件齐全（缺段即报）
- 音频可读（ffprobe）
- 时长异常预警：单段 <2s，或与按 4.5 字/秒估算偏差超 40%

依赖：系统装有 ffmpeg（含 ffprobe），无需 pip 包。
