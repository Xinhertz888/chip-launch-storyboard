# 参考配音样本（你的声音）

把 1~3 段配音样本放进这个目录，文件名如 `sample1.mp3`。

## 录制要求（直接影响克隆效果）

- 每段 **8~10 秒**，吐字清晰、音量稳定、情绪自然（就用你平时录「芯品发布会」的语气）
- 无背景音乐、无杂音、无房间回声
- 格式：mp3（192kbps 以上）或 wav

## 文字稿

每段音频配一个同名 `.txt`，里面写**这段音频的完整文字内容**（逐字一致），例如：

```
sample1.mp3  ->  sample1.txt
```

上传音色时需要这个文字稿：

```bash
python ../dub.py upload-voice --audio reference/sample1.mp3 \
    --text "$(cat reference/sample1.txt)" --name xinpin-voice
```

> 注意：本仓库是公开的，上传到这里的样本任何人可见。
> 这个声音本来就是「芯品发布会」视频里公开发布的声音，请自行权衡。
