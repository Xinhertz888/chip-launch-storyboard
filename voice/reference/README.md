# 参考配音样本（你的声音）

> 已入库：`sample1.mp3` ~ `sample6.mp3`（2026-10-18，ADC34DSO75 第一期分镜配音），
> 为「芯品发布会」基准音色。新增样本按同样规范放入即可。

## 录制要求（作为统一音色的基准）

- 每段 **8~10 秒**，吐字清晰、音量稳定、情绪自然（就用你平时录「芯品发布会」的语气）
- 无背景音乐、无杂音、无房间回声
- 格式：mp3（192kbps 以上）或 wav

## 文字稿

每段音频配一个同名 `.txt`，里面写**这段音频的完整文字内容**（逐字一致），例如：

```
sample1.mp3  ->  sample1.txt
```

文字稿用于 `check.py` 质检时核对"音频时长 vs 文字量"是否匹配。

## agent 调用方式

新一期配音录好后，跑 `python check.py --segs <分段目录> --script <配音稿txt> --out <输出目录>`，
质检通过即得 `manifest.json`（每段精确时长），直接用于排分镜时间轴。
