# chip-launch-storyboard

抖音账号「芯品发布会」的芯片新品视频 skill：给新型号，查资料，只交付分镜脚本。

## 用法

把芯片型号发给装有本 skill 的 AI，它会自动：

1. 查 datasheet 与官方发布，核验芯片类型 / 用途 / 应用 / 关键参数
2. 定一句话卖点
3. 输出 45–60 秒竖版分镜脚本（含中文配音稿与字幕时间轴）

## 默认规格

- 9:16 竖版（1080×1920），45–60 秒（以讲清楚这是什么芯片为准），60fps，120 BPM
- 中文配音＋中文字幕；口播文案、配音稿、字幕为同一份稿子，逐字一致
- 固定开场白：「芯品发布会，一分钟带你看懂最新芯片。」
- BGM：免版权电子乐三段式（实现侧自选）
- 动画实现：Opus 5.5 代码动画（先配音定出时长，再做画面）

## 文件

- `SKILL.md`：工作流（流程 / 默认规格 / 三段式 / 红线）
- `skill.yaml`：skill 元信息
- `references/storyboard-template.md`：分镜脚本通用模板
